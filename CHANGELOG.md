## [0.1.0] - 2026-09-09
 
MVP: базовая функциональность трекера воды, без продвинутой архитектуры — цель была
проверить, что идея работает целиком, от клика в интерфейсе до записи в базе.
 
### Added
- Backend на FastAPI: эндпоинты `GET /api/logs`, `POST /api/logs`, `DELETE /api/logs/{id}`
- Асинхронная работа с SQLite через SQLAlchemy (`aiosqlite`)
- Таблица `water_logs`: тип напитка, объём, коэффициент гидратации, привязка к приёму пищи, комментарий, время записи
- Автоматическое создание таблиц при старте приложения (без миграций — не нужны на этом этапе)
- Frontend: мобильный HTML/CSS/JS-интерфейс без фреймворка
  - Наполняемый стакан с анимацией волны
  - Быстрое добавление напитков (вода/чай/кофе/сок) с учётом коэффициента гидратации
  - Полная форма добавления записи: тип, количество, до/после еды, комментарий
  - Тост с отменой последнего действия (undo)
  - Боковое меню: заглушки для настроек и друзей, календарь с демо-heatmap, история записей с удалением
  - Раздел "Заметки" с демо-контентом (факты, рецепты, новости проекта)
  - Зарезервированное место под будущий чат с ИИ
- Frontend подключён к реальному API вместо моковых данных
- Docker: контейнеризация backend + отдача статики фронтенда одним процессом
- `LICENSE` — MIT
