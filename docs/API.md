# API Reference

Краткая карта эндпоинтов для FastAPI. Базовый префикс: `/api`

---

## Water logs

Записи о выпитом.

| Метод    | Путь                      | Описание                    | Статус |
|----------|---------------------------|------------------------------|--------|
| `GET`    | `/water-logs`              | список записей за сегодня    | ✅ готово |
| `POST`   | `/water-logs`               | добавить запись               | ✅ готово |
| `DELETE` | `/water-logs/{id}`          | удалить запись                | ✅ готово |

Фильтрация по дате/диапазону — через query-параметры, не отдельные пути:
```
GET /water-logs?date=2026-09-25
GET /water-logs?from=2026-09-01&to=2026-09-30
```
*(пока не реализовано)*

## Drink types

Справочник напитков с коэффициентом гидратации.

| Метод | Путь           | Описание           | Статус |
|-------|----------------|---------------------|--------|
| `GET` | `/drink-types`  | список типов напитков | ✅ готово |

Список сидируется автоматически при старте приложения (вода/чай/кофе/сок).

## Profile

Профиль пользователя — данные для расчёта дневной нормы воды.

| Метод   | Путь        | Описание                             | Статус |
|---------|-------------|----------------------------------------|--------|
| `GET`   | `/profile`   | текущий профиль                       | 🚧 план |
| `PATCH` | `/profile`   | частичное обновление (вес, пол, активность, город) | 🚧 план |

> `PATCH`, а не `PUT` — обновление всегда частичное (`exclude_unset=True`),
> не требует пересылки всего объекта целиком.

## Stats

Агрегированные метрики поверх `water-logs`, не самостоятельный CRUD-ресурс.

| Метод | Путь              | Описание                          | Статус |
|-------|-------------------|-------------------------------------|--------|
| `GET` | `/stats/streak`    | текущий стрик (дней подряд с целью) | 🚧 план |
| `GET` | `/stats/heatmap`   | данные по дням для календаря-heatmap | 🚧 план |

## Journal

Контент раздела "Заметки" (рецепты, факты, новости проекта).

| Метод | Путь           | Описание           | Статус |
|-------|-----------------|----------------------|--------|
| `GET` | `/journal`       | список постов        | 🚧 план |
| `GET` | `/journal/{id}`  | один пост             | 🚧 план |

Пишутся вручную/через базу, без публичного `POST` — контент ведёт не пользователь.

## Конвенции

- Множественное число для коллекций (`/water-logs`), единственное — implicit
  для одного элемента по `{id}` (`/water-logs/5`)
- Фильтрация — через query-параметры, не через дополнительные сегменты пути
- Действие = HTTP-метод, путь = ресурс. Никаких `/get-`, `/add-`, `/delete-` в URL
- `/stats/*` — отдельный неймспейс для агрегатов, которые не являются CRUD-сущностями
